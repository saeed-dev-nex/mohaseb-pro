# افزونهٔ فایرفاکس محاسب

## نصب توسعه‌ای موقت

برای آزمایش کد، از `about:debugging` → `This Firefox` → `Load Temporary Add-on` استفاده کنید و `manifest.json` را انتخاب کنید. این نصب موقت است و با بستن یا راه‌اندازی دوبارهٔ Firefox از بین می‌رود؛ برای استفادهٔ روزمره باید نسخهٔ امضاشده را نصب کنید.

## نصب پایدار

Firefox پایدار افزونهٔ دائمی را پس از امضای Mozilla نصب می‌کند. برای ساخت بستهٔ ارسال به AMO:

```powershell
.\package.ps1
```

فایل `release/mohaseb-pro-firefox-<version>.zip` برای بارگذاری در AMO ساخته می‌شود. این ZIP فایل نصب نهایی نیست. در AMO گزینهٔ **On your own** را انتخاب کنید تا افزونه فهرست عمومی نشود؛ پس از امضا، فایل `.xpi` امضاشده را دریافت و از `about:addons` → منوی چرخ‌دنده → **Install Add-on From File** نصب کنید.

راهنمای تصویری کامل نصب، امضا، عیب‌یابی و تفاوت نصب موقت و پایدار: [`INSTALL_FIREFOX_FA.md`](INSTALL_FIREFOX_FA.md).

## استفاده

روی آیکون افزونه کلیک کنید تا پنجرهٔ مستقل فاکتور باز شود. پنجره قابل جابه‌جایی و تغییر اندازه است و آخرین جایگاهش حفظ می‌شود. کلیک دوباره روی آیکون آن را کوچک می‌کند؛ بستن پنجره با دکمهٔ پنجره، با کلیک روی آیکون دوباره آن را باز می‌کند. پیش‌نویس فاکتور در ذخیره‌سازی محلی افزونه حفظ می‌شود.

افزونه به API محلی در `http://localhost:8000` وصل می‌شود؛ سرور backend باید روی همان رایانه‌ای که Firefox اجرا می‌شود فعال باشد.

نسخهٔ `1.1.2` حداقل Firefox 140 را پشتیبانی می‌کند و در نصب، دسته‌های دادهٔ ورود حساب، اطلاعات هویتی مشتری و اطلاعات مالی فاکتور را به Firefox اعلام می‌کند. مجوز میزبان برای `localhost` تعریف شده و API برنامه روی پورت 8000 استفاده می‌شود.
