# افزونهٔ فایرفاکس محاسب

## نصب توسعه‌ای موقت

برای آزمایش کد، از `about:debugging` → `This Firefox` → `Load Temporary Add-on` استفاده کنید و `manifest.json` را انتخاب کنید. این روش فقط برای آزمایش است و افزونه با خروج از Firefox حذف می‌شود.

## نصب پایدار

Firefox نسخهٔ پایدار، افزونهٔ دائمیِ خارج از AMO را فقط پس از امضای Mozilla نصب می‌کند. بستهٔ زیر را بسازید و در پنل توسعه‌دهندگان AMO به‌عنوان افزونهٔ Unlisted بارگذاری کنید؛ پس از امضا، فایل `.xpi` را با Firefox باز کنید تا افزونه پس از راه‌اندازی مجدد باقی بماند.

```powershell
.\package.ps1
```

خروجی برای بارگذاری در AMO در `release/mohaseb-pro-firefox-1.1.0.zip` ساخته می‌شود. این ZIP برای ارسال به AMO است و هنوز فایل نصب امضاشده نیست.

## استفاده

روی آیکون افزونه کلیک کنید تا پنجرهٔ مستقل فاکتور باز شود. پنجره قابل جابه‌جایی و تغییر اندازه است و آخرین جایگاهش حفظ می‌شود. کلیک دوباره روی آیکون آن را کوچک می‌کند؛ بستن پنجره با دکمهٔ پنجره، با کلیک روی آیکون دوباره آن را باز می‌کند. پیش‌نویس فاکتور در ذخیره‌سازی محلی افزونه حفظ می‌شود.
